规则 / 关于

基本走法：车走直线、马走日蹩腿、相走田塞眼且不过河、士走斜线限九宫、帅走一格限九宫、炮隔子吃子、兵过河后可横走。
胜负：吃掉或将死对方将/帅即获胜；无子可走且被将 = 将死（负），未被将 = 困毙（和）。
和棋：三次重复局面、60 回合无吃子无动兵。
犯规：连续将军超 12 手（长将）判负；拖超时判负。
操作：鼠标点击或键盘 — 方向键移动光标、空格选子/落子、U 悔棋、H 提示、Esc 返回。
隐私与合规：本游戏为纯前端单机应用，所有数据（设置、战绩、棋谱）仅保存在你的浏览器本地，不上传服务器。不含付费、抽奖、概率玩法与虚拟货币。
错误监控 / 埋点：本地记录最近 100 条诊断与行为事件（仅本机），用于定位问题。
版本：v2.0 · 单文件离线可用
技术：原生 HTML5 + CSS3 + JavaScript（SVG 棋盘、Web Audio 音效、Canvas 粒子、BroadcastChannel 联机、LocalStorage 持久化）
